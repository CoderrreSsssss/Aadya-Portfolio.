# Aadya Singh | Photography Portfolio

## Deploy
Upload everything in this folder to a GitHub repository (package.json must be at the top level), then import it in Vercel with default Vite settings.

## Photos
Put photographs in `public/images/` (JPG, JPEG, PNG, WEBP). They are found automatically. Titles, categories and captions are in `src/data/portfolioData.js` (the `details` block). Files match by name, so `.jpg` and `.jpeg` both work. The photo `IMG_9595` is used in "Behind the Lens"; `heroStems` sets the hero slideshow photos.

## Categories
Portrait, Nature, Street, Architecture, Creative and Travel. To add one, add it to `categories` in `portfolioData.js`.

## Colours
`theme` in `portfolioData.js`: 'sunrise', 'light', 'sage' or 'night'. Palettes are in `src/index.css`.
